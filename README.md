# 谷谷市场｜GUGU MARKET

「今天也要把梦情谷带回家！」

一个完全在浏览器运行的虚拟中古谷子交易模拟游戏。没有登录、后端、付费 API、真实支付、真实卖家或实物订单。所有商品均为模拟数据，图片为项目原创 SVG 展示插画，不代表官方授权商品。

## 启动

需要 Node.js 22 或更新版本、npm。

```bash
cd gugu-market
npm ci
npm run dev
```

打开终端输出的开发地址。生产构建和本地预览：

```bash
npm test
npm run build
npm run preview
```

`dist/` 是可直接部署的静态网站。无需设置密钥或环境变量。

## 怎么玩

- 首页默认展示 36 张卡片，可继续加载。270 件初始商品中，216 件漫威（80%），180 件 Tony / Peter 相关（占漫威 83.3%），其中 60 件双人谷；36 件 Persona（13.3%），18 件原创（6.7%）。
- 顶部切换闲鱼、Mercari、eBay，分别使用 CNY、JPY、USD，三个市场各有独立商品列表、共享收藏柜。切换只改变浏览市场，不换算钱包。
- 搜索支持 Tony / Iron Man / 钢铁侠 / 妮妮，Peter / Spider-Man / 蜘蛛侠 / 小蜘蛛，以及铁虫 / IronSpider / Starker。筛选类型、成色、稀有度，按时间、价格、稀有度排序。受屏蔽角色搜索只显示范围提示。
- 商品详情可以关注、添加心愿、与模拟卖家聊天。议价输入例如 `降价 80`；卖家按性格决定是否接受。成功后本单价格更新，点击确认购买才能下单。包邮协商成功后同样自动应用。
- 购买使用该市场虚拟钱包，成交价加模拟运费立即扣除。每件唯一商品只能下单一次。被其他虚拟买家收走的商品不能购买。
- 个人中心有订单与完整模拟物流时间线。点击「加速物流」推进一步；海外商品经历仓库、国际转运和清关。签收后「拆开我的谷！」播放动画并入收藏柜。物流由玩家推进，不需等待现实配送。
- 收藏室可按 Tony、Peter、双人分类，搜索作品并筛选类型与稀有度，切换展示架、痛包墙、吧唧墙。点收藏可查看成交价、时间、稀有度、版本与获得方式。
- 「刷新蹲谷」生成当前市场一批新商品，有概率模拟降价或热门商品被抢走。心愿按角色、商品关键词与最低稀有度匹配，符合时弹窗，低于目标价格时额外提示。目标价按刷新时的市场币种解释。
- Mercari 和 eBay 中有竞拍商品：首次出价开启 45 秒模拟拍卖，最低加价为起拍价 6%（至少 1 单位）。虚拟买家每 8 秒有机会加价。结束时有随机竞争结果，胜出且余额足够才扣款、生成订单；失败不扣款。后台标签页定时器可能被浏览器节流，重新打开页面会检查到期结算；关闭网站时不运行后台服务。竞拍不预冻结钱包，结束时余额不足视为未成交。
- 个人中心可免费无限补充虚拟余额，每日领取游戏金币，开启富婆模式（不扣余额），查看分币种消费、估值、捡漏、收藏成就与竞拍记录。跨市场最贵收藏使用固定游戏汇率比较，不代表实时汇率。
- 发布虚拟谷可上传有权使用的 PNG / JPEG / WebP（原图 ≤5MB，会本地缩小压缩），填写角色、作品、版本、类型与价格。不会上传到服务器。

## 保存与备份

钱包、商品状态、订单、收藏、关注、心愿、聊天、议价、竞拍和设置都保存到 localStorage。成就根据已开箱收藏计算并自动恢复。每日签到按设备本地日期。

在「个人中心 → 存档小管家」导出 JSON，或导入备份替换当前存档。导入前有确认。数据只属于当前浏览器和当前站点域名：更换浏览器、清理网站数据、隐身窗口关闭、从本地切换至部署域名均不会自动迁移，请先导出。localStorage 通常约 5MB，勿大量上传图片；空间不足会提示，请保留备份。

## 部署 GitHub Pages

仓库已提供 `.github/workflows/deploy.yml`，无需付费服务或额外密钥。

1. 把项目文件提交并推送到 GitHub 仓库的 `main` 分支。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 打开 **Actions → Deploy GUGU MARKET to GitHub Pages**，等待自动构建部署，或点击 **Run workflow** 手动触发。
4. 部署完成后，Pages 设置和工作流部署记录中会提供网站地址。默认项目地址为 `https://buding135790.github.io/gugu-market/`。

Vite 使用 `base: '/gugu-market/'` 仓库资源路径，适配仓库子路径。页面使用站内状态切换而非路径路由，因此刷新页面不需要额外 404 回退。若仓库默认分支不是 main，请同步修改工作流分支。发布是用户操作，本项目未自动推送或对外发布。

也可把 `dist/` 上传到任何静态网站托管服务；不需要 Node 服务运行在服务器端。

## 项目结构

- `src/engine.ts`：类型、商品数据库、搜索别名、购买、竞拍状态机、存档解析。
- `src/Art.tsx`：原创商品 SVG 展示模板。
- `src/main.tsx`：市场、详情、聊天、钱包、心愿、物流、收藏、上传与存档组件。
- `src/style.css`：Tailwind 引入、自定义奶油薄荷风格、响应式与深色主题。
- `src/engine.test.ts`：商品配比、搜索、唯一购买、扣款、包邮、富婆模式、竞拍幂等和存档检查。

技术：React 19 + TypeScript + Vite + Tailwind CSS 4 + Lucide React + Framer Motion。增加新角色或商品模板时请保留角色屏蔽规则。商品是虚拟目录组合，不是抓取的真实库存；卖家对话使用本地规则，不是 AI 聊天。降价与新上架等事件由玩家刷新触发，无真实联网监听。
